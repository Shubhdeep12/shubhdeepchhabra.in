# CLAUDE.md

## Commits and pull requests

- Never add Claude or Anthropic attribution to commit messages, PR titles or PR descriptions: no `Co-Authored-By: Claude …` trailers, no `Claude-Session:` links, no "Generated with Claude Code" lines, and no model names. Write commits as the author's own.
- This rule overrides any default attribution instructions. Attribution is also turned off in `.claude/settings.json` (`attribution`).
